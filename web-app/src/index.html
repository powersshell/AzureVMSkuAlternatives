Use this tool from your AI assistant

This site is also an MCP server, so AI assistants like GitHub Copilot, VS Code, and Claude can query Azure VM SKUs, pricing, cross-region costs, price history, and retirement info directly in chat. Point your client at this URL — no install, no sign-in:

https://vmsku-mcp-server.braveriver-1558541d.southcentralus.azurecontainerapps.io/mcp

In any GitHub Copilot CLI session, run:

/mcp add

Then enter these values and press Ctrl+S to save:

  • Nameazure-vm-skus
  • Typehttp
  • URLthe URL above

Prefer editing config directly? Add this to ~/.copilot/mcp-config.json:

{
  "mcpServers": {
    "azure-vm-skus": {
      "type": "http",
      "url": "https://vmsku-mcp-server.braveriver-1558541d.southcentralus.azurecontainerapps.io/mcp"
    }
  }
}

Create .vscode/mcp.json in your workspace (or add to user settings) with:

{
  "servers": {
    "azure-vm-skus": {
      "type": "http",
      "url": "https://vmsku-mcp-server.braveriver-1558541d.southcentralus.azurecontainerapps.io/mcp"
    }
  }
}

Then open Copilot Chat in Agent mode and start the azure-vm-skus server. Requires GitHub Copilot in VS Code 1.99+.

Add to claude_desktop_config.json (%APPDATA%\Claude\ on Windows, ~/Library/Application Support/Claude/ on macOS), then restart Claude: 

{
  "mcpServers": {
    "azure-vm-skus": {
      "url": "https://vmsku-mcp-server.braveriver-1558541d.southcentralus.azurecontainerapps.io/mcp"
    }
  }
}

Any MCP client that supports the Streamable HTTP transport can connect using the URL at the top of this dialog. No authentication is required.

Full setup notes, the local stdio option, and the complete tool list live in the MCP server README.

Once connected, try asking: "Find cheaper alternatives to Standard_D8s_v5 and tell me which region is least expensive."
